# 多頁面電子書 App｜蕭邦・波蘭舞曲

## 一、製作動機與 App 簡介

這次我以「蕭邦的波蘭舞曲」為主題製作多頁面電子書 App。波蘭舞曲不只是音樂作品，也承載了蕭邦對故鄉、歷史與民族精神的情感。因此，我把作品依創作時期整理成時間線，並加入作品導讀、有聲書、影片與官方網站，讓使用者不只閱讀文字，也能用聽覺與影像認識作品。

App 共有「時間線、作品、有聲書、影像、官方網站」五個主要分頁，支援 iPhone 與 iPad、深色與淺色模式，並加入開場動畫、卡片轉場、SF Symbol 動畫及減少動態效果支援。

## 三、基本功能

### 1. 開發多頁面 App，新增檔案定義頁面

專案將資料、共用元件及各頁面分開定義，例如：

- ContentView：主要 TabView
- TimelineView：創作時間線
- WorksView：作品表格
- WorkDetailView：作品詳細內容
- AudiobookPagesView：水平滑動有聲書
- VideoGalleryView：影片頁面
- ChopinWebView：官方網站
- OpeningView：開頭畫面
- PolonaiseData：自訂資料型別與作品陣列

這樣能避免所有程式碼擠在同一個檔案，也方便後續維護。

### 2. 使用 TabView 與 Tab 製作分頁

主畫面包含五個 Tab。iPhone 顯示下方 tab bar，iPad 使用 sidebarAdaptable，自動適應成上方 tab bar 或側邊欄。

```swift
struct ContentView: View {
    var body: some View {
        TabView {
            Tab("時間線", systemImage: "clock.arrow.circlepath") {
                TimelineView()
            }

            Tab("作品", systemImage: "music.note.list") {
                WorksView()
            }

            Tab("有聲書", systemImage: "headphones") {
                AudiobookPagesView()
            }

            Tab("影像", systemImage: "play.rectangle") {
                VideoGalleryView()
            }

            Tab("官方網站", systemImage: "globe") {
                ChopinWebView()
            }
        }
        .tabViewStyle(.sidebarAdaptable)
    }
}
```

### 3. NavigationStack、NavigationLink 與資料傳遞

作品清單以 NavigationLink 傳入使用者選擇的 PolonaiseChapter，詳細頁再顯示作品資料，navigation bar 也有標題。

```swift
NavigationStack {
    List(PolonaiseData.chapters) { chapter in
        NavigationLink(value: chapter) {
            WorkRow(chapter: chapter)
        }
    }
    .navigationTitle("波蘭舞曲作品")
    .navigationDestination(for: PolonaiseChapter.self) { chapter in
        WorkDetailView(chapter: chapter)
            .navigationTitle(chapter.catalog)
            .navigationBarTitleDisplayMode(.inline)
    }
}
```

### 4. Array、自訂 struct 與 Identifiable

每首作品都使用自訂型別表示，並遵從 Identifiable 與 Hashable，因此可直接搭配 List、ForEach 與 NavigationLink。

```swift
struct PolonaiseChapter: Identifiable, Hashable {
    let id: String
    let year: Int
    let title: String
    let originalTitle: String
    let catalog: String
    let key: String
    let duration: String
    let audioURL: URL?
    let period: String
    let introduction: String
    let listeningGuide: String
}

enum PolonaiseData {
    static let chapters: [PolonaiseChapter] = [
        PolonaiseChapter(
            id: "op40-no1",
            year: 1838,
            title: "軍隊波蘭舞曲",
            originalTitle: "Polonaise in A major",
            catalog: "Op. 40, No. 1",
            key: "A 大調",
            duration: "約 5 分鐘",
            audioURL: nil,
            period: "成熟時期",
            introduction: "以雄壯節奏展現波蘭舞曲的英雄氣質。",
            listeningGuide: "留意開頭強而有力的和弦與規律節奏。"
        )
    ]
}
```

實際專案中的陣列收錄完整作品資料，不只以上示範的一筆。

### 5. 使用 List 製作表格

作品頁用 List 呈現陣列資料，也加入播放與典藏的滑動操作。

```swift
List {
    ForEach(PolonaiseData.chapters) { chapter in
        NavigationLink(value: chapter) {
            WorkRow(chapter: chapter)
        }
        .swipeActions(edge: .leading) {
            Button {
                play(chapter)
            } label: {
                Label("播放", systemImage: "play.fill")
            }
            .tint(.blue)
        }
        .swipeActions(edge: .trailing) {
            Button {
                toggleFavorite(chapter)
            } label: {
                Label("典藏", systemImage: "bookmark.fill")
            }
            .tint(.orange)
        }
    }
}
```

「作品」負責瀏覽全部資料，「典藏」只是作品的收藏狀態與操作，因此不再另外建立內容重複的主分頁。

### 6. 使用 page 實現水平滑動

有聲書依不同創作時期分頁，使用者可左右滑動，也可從頁面指示器看目前位置。

```swift
TabView(selection: $selectedPage) {
    ForEach(
        Array(ChopinPeriodCatalog.periods.enumerated()),
        id: \.element.id
    ) { index, period in
        AudiobookPeriodPage(period: period)
            .tag(index)
    }
}
.tabViewStyle(.page(indexDisplayMode: .always))
.indexViewStyle(.page(backgroundDisplayMode: .always))
```

### 7. 使用 WebView 顯示網頁

官方網站直接顯示在 App 內，不必跳出 Safari，並提供上一頁、下一頁與重新整理功能。

```swift
import SwiftUI
import WebKit

struct ChopinWebView: View {
    @State private var page = WebPage()

    var body: some View {
        NavigationStack {
            WebView(page)
                .navigationTitle("蕭邦官方網站")
                .toolbar {
                    ToolbarItemGroup(placement: .bottomBar) {
                        Button("上一頁", systemImage: "chevron.backward") {
                            page.goBack()
                        }
                        .disabled(!page.backForwardList.backList.isEmpty == false)

                        Button("下一頁", systemImage: "chevron.forward") {
                            page.goForward()
                        }

                        Spacer()

                        Button("重新整理", systemImage: "arrow.clockwise") {
                            page.reload()
                        }
                    }
                }
                .task {
                    guard let url = URL(
                        string: "https://chopin.pl/"
                    ) else { return }
                    for await _ in page.load(URLRequest(url: url)) {}
                }
        }
    }
}
```

### 8. 設定開頭畫面

Info.plist 設定系統 Launch Screen：

```xml
<key>UILaunchScreen</key>
<dict/>
```

系統開頭畫面結束後，再顯示自製 OpeningView，讓標題、鋼琴與音符以動畫進場。

```swift
@State private var isOpeningVisible = true

var body: some View {
    ZStack {
        ContentView()

        if isOpeningVisible {
            OpeningView {
                withAnimation(.easeInOut(duration: 0.7)) {
                    isOpeningVisible = false
                }
            }
            .transition(.opacity.combined(with: .scale(scale: 1.04)))
        }
    }
}
```

## 四、加分功能

### 1. 生動有趣的 SwiftUI animation

開頭畫面不是單純淡入淡出，而是讓內容依階段產生縮放、位移與透明度變化。

```swift
phaseAnimator([false, true]) { content, active in
    content
        .scaleEffect(active ? 1 : 0.82)
        .opacity(active ? 1 : 0)
        .offset(y: active ? 0 : 24)
} animation: { _ in
    .spring(response: 0.9, dampingFraction: 0.72)
}
```

### 2. SF Symbol 動畫

```swift
Image(systemName: "music.note")
    .font(.system(size: 34))
    .symbolEffect(.pulse, options: .repeating)
```

畫面周圍也有旋轉音符與浮動效果，使音樂主題更明顯。

### 3. transition 元件出現動畫

```swift
if showDetail {
    DetailCard()
        .transition(
            .asymmetric(
                insertion: .scale.combined(with: .opacity),
                removal: .opacity
            )
        )
}
```

### 4. 支援「減少動態效果」

```swift
@Environment(\.accessibilityReduceMotion)
private var reduceMotion

withAnimation(reduceMotion ? nil : .spring()) {
    isExpanded.toggle()
}
```

使用者若在系統開啟 Reduce Motion，App 會減少不必要的大幅動畫。

### 9. 使用 VideoPlayer 播放本地影片

```swift
import AVKit

struct LocalVideoView: View {
    private var player: AVPlayer? {
        guard let url = Bundle.main.url(
            forResource: "chopin",
            withExtension: "mp4"
        ) else { return nil }
        return AVPlayer(url: url)
    }

    var body: some View {
        if let player {
            VideoPlayer(player: player)
                .aspectRatio(16 / 9, contentMode: .fit)
        } else {
            ContentUnavailableView(
                "找不到影片",
                systemImage: "video.slash"
            )
        }
    }
}
```

## 六、製作心得

這次製作過程中，我不只練習了 SwiftUI 的多頁面架構，也學會如何讓資料、導覽與畫面互相配合。最困難的部分是避免不同頁面的內容重複，因此最後將「作品」作為主要瀏覽入口，「典藏」改成作品的收藏功能；同時利用有聲書、影片與網站，讓每個分頁都有明確用途。

動畫部分也不只是為了裝飾。開場動畫負責建立主題氣氛，卡片 transition 幫助使用者理解畫面變化，SF Symbol 動畫則提供操作回饋。加入 Reduce Motion 後，也讓效果兼顧使用者的系統設定。

完成這個 App 後，我對 TabView、NavigationStack、List、WebView、VideoPlayer、資料模型與響應式版面有更完整的理解，也更能掌握如何把電子書做成兼具閱讀、聆聽與互動體驗的作品。
